COMO ABRIR O DARKSTAR FORGE
===========================

OPÇÃO 1 (recomendada — sem terminal)
  • Duplo clique em:  ABRIR-DARKSTAR-FORGE
  • Se o sistema pedir: botão direito → Propriedades → "Executável como programa"
  • Ou no menu de aplicativos: "Darkstar Forge"

OPÇÃO 2 (terminal)
  cd "/home/djabo/Downloads/Darkstar Forge"
  ./ABRIR-DARKSTAR-FORGE

OPÇÃO 3 (servidor com API de artes — recomendado no terminal)
  cd "/home/djabo/Downloads/Darkstar Forge"
  python3 tools/serve.py 8765
  Depois abra: http://127.0.0.1:8765/

OPÇÃO 4 (servidor simples Python)
  python3 -m http.server 8765 --bind 127.0.0.1

ARTES:
  • Upload no editor salva na biblioteca do programa (IndexedDB)
    e reaparece para reutilizar em qualquer carta.
  • Pasta assets/artwork/ também entra na lista (seed).
  • No app instalado (.exe / AppImage) as artes de upload
    ficam no perfil do usuário — não precisam da pasta.

Ícone do programa (atalho / Tauri):
  assets/icons/set/logo.png

INSTALADOR (Windows / Linux):
  veja docs/INSTALADOR.md e a página Releases do GitHub.
  O amigo só baixa o instalador e clica — sem comandos.

NÃO execute arquivos .desktop como se fossem scripts de shell —
use o ABRIR-DARKSTAR-FORGE.

URL: http://127.0.0.1:8765/
